# Woojoo v0.1.5

- 왼쪽 메뉴에서 데이터베이스와 HTTP API 작업 공간을 사용할 수 있습니다.
- AWS, Docker, Redis 작업 공간은 [별도 브랜치](https://github.com/leessang10/woojoo-db/tree/codex/infrastructure-workspaces)에 보존했습니다. 기존 RDS 연결 프로필은 DB 작업 공간에서 계속 사용할 수 있습니다.
- 기존 앱을 종료한 뒤 Windows x64 실행 파일로 교체하세요. Microsoft WebView2가 필요하며 실행 파일은 코드 서명되어 있지 않습니다.
- SHA256SUMS.txt에서 실행 파일 체크섬을 확인할 수 있습니다.

## 검증

- 프런트엔드 단위 테스트 83개, 브라우저 UI 테스트 105개, Rust 테스트 30개 통과. 별도 DB 환경이 필요한 Rust 테스트 3개는 기본 실행에서 제외했습니다.
- 배포 EXE에서 개발 서버 없이 SQLite 테이블 생성, 탭과 연결 전환, 로컬 HTTP 요청 및 JSON 응답 표시를 확인했습니다.
