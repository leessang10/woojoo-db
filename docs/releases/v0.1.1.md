# Woojoo v0.1.1

Windows 연결 편의성과 작업 화면의 일관성을 개선했습니다.

## 주요 변경

- AWS RDS CA 인증서로 TLS 서버 인증서를 검증합니다.
- 선택 시 Windows 자격 증명 관리자에 비밀번호를 저장하고 앱 재시작 후 마지막 연결에 자동 접속합니다. 프로필 파일에 비밀번호를 저장하지 않습니다.
- AWS 프로필(계정)과 리전을 선택하면 RDS 인스턴스 목록을 자동으로 조회합니다. 계정 정보와 로딩 표시 위치를 정리하고, 리전 변경 후 늦게 도착한 이전 응답을 무시합니다.
- 탭 메뉴에 모든 탭·다른 탭·오른쪽 탭·왼쪽 탭 닫기를 추가했습니다. 저장하지 않은 변경은 닫기 전에 확인합니다.
- 탭과 SQL 도구 모음의 스크롤바를 숨기고 마우스 휠 스크롤을 지원합니다. 자주 쓰는 SQL을 SQL 도구 모음으로 옮겼습니다.
- 쿼리 실패 시 이전 성공 결과임을 표시하며, 오류 메시지를 닫아도 안내를 유지합니다.
- SQL 편집기 접기·펼치기 및 높이 조절, 데이터 도구 필터 배치, 작은 창에서의 연결창 하단 버튼 노출을 개선했습니다.
- SQL 기록·도움말·연결창의 간격과 버튼 규격을 통일했습니다. 구조 화면의 전체 작업과 탭별 작업을 일정한 위치에 배치했습니다.
- SQL 기록과 실행한 쿼리의 용도, DB 처리 시간과 전체 소요 시간, ERD 변경 검토 안내를 명확히 했습니다.

## 다운로드

- `Woojoo-0.1.1-windows-x64.exe`: 설치 없이 실행하는 Windows x64 앱. Microsoft WebView2 런타임이 필요합니다.
- `SHA256SUMS.txt`: 배포 실행 파일의 SHA-256 체크섬.
- 실행 파일은 코드 서명되어 있지 않습니다. 업데이트 전 기존 앱을 종료하고 새 EXE로 교체하세요. 기존 프로필과 사용자 데이터는 유지됩니다.

AWS 화면 자동 테스트는 모의 응답을 사용합니다. 이번 릴리즈 검증에서 실제 AWS 계정과 RDS 서버에 재접속하지 않았습니다.

## 검증

- 프런트엔드 단위 테스트: 33개 통과.
- UI 테스트: 전체 81개 중 최초 실행 73개 통과. 변경된 UI 기대값을 수정하고 실패 8개를 단독 재실행하여 모두 통과했습니다.
- Rust 테스트: 29개 통과, 외부 환경이 필요한 4개 제외.
- TypeScript/Vite 빌드 통과.
- Windows x64 최적화 빌드 통과. 개발 서버를 종료한 상태에서 배포 EXE의 시작·새로고침·SQLite 연결·탭 조작·프로필 전환 검증을 통과했습니다.
