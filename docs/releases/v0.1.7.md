# Woojoo v0.1.7

- 상단에서 연결 → 스키마 → 테이블을 검색하고 선택할 수 있습니다. 연결 상태는 연결 이름 옆의 점으로 표시하며, 사이드바를 접어도 탐색할 수 있습니다.
- 연결 정보와 데이터 도구의 배치를 정리하고 테이블 보기의 중복 도구 모음을 줄였습니다.
- 숫자, 문자열, 날짜·시간, 불리언, JSON, 바이너리, NULL을 타입별 글자색으로 구분합니다. 실제 NULL은 회색 기울임꼴로 표시합니다.
- FK 셀의 화살표로 참조 행을 열고, PK 메뉴에서 원본 행과 참조하는 행으로 이동할 수 있습니다. 복합키와 다른 스키마의 관계를 지원합니다.
- 관계 이동은 읽기 전용 연결에서도 사용할 수 있으며, NULL 키와 수정 중인 행에서는 잘못된 이동을 막습니다.
- Windows x64 실행 파일과 SHA-256 체크섬을 제공합니다. Microsoft WebView2가 필요하며 실행 파일은 코드 서명되어 있지 않습니다.

## 검증

- 단위 테스트 90개, Rust 테스트 30개 통과. 별도 서버·인증이 필요한 통합 테스트 3개는 제외됩니다.
- 브라우저 UI 검사 110개 중 107개 통과 후, 셀 접근성 이름을 수정하고 실패 3개를 단독 재검증하여 모두 통과했습니다. 신규 관계 이동과 밝은·어두운 테마의 타입별 색상 검사도 통과했습니다.
- 배포 EXE에서 개발 서버 없이 SQLite FK·역참조 이동, 타입별 NULL 구분, 사이드바를 접은 상태의 테이블 선택, SQL 도구, 탭 전환 및 실제 HTTP 요청을 확인했습니다.
