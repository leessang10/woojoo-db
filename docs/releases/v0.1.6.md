# Woojoo v0.1.6

- 테이블을 열면 SQL 편집기가 접힌 상태로 데이터를 먼저 표시합니다. SQL 펼치기로 편집할 수 있으며 새 쿼리는 편집기를 펼쳐 시작합니다.
- SQL을 접으면 파일, 정렬, 스크립트 실행 도구와 실행 스키마 선택기도 함께 접힙니다. 진행 중인 트랜잭션의 제어와 쿼리 중지는 계속 표시합니다.
- 선택한 행의 상세 패널과 이전·다음 행 이동을 추가하고 데이터 그리드의 표시 밀도를 개선했습니다.
- Windows x64 실행 파일과 SHA-256 체크섬을 제공합니다. Microsoft WebView2가 필요하며 실행 파일은 코드 서명되어 있지 않습니다.

## 검증

- 단위 테스트 85개 통과.
- 브라우저 UI 검사 106개 통과 후, 접힌 SQL의 실행 버튼을 찾던 기존 검사 1개를 새 화면 흐름에 맞춰 갱신하고 재검증을 통과했습니다.
- 배포 EXE에서 개발 서버 없이 SQL 도구 접기·펼치기, SQLite 테이블 생성, 탭·연결 전환, 실제 HTTP 요청과 JSON 응답을 확인했습니다.
