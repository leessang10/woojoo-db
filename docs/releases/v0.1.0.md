# Woojoo v0.1.0

Woojoo의 첫 공개 릴리즈입니다. React/TypeScript와 Tauri/Rust 기반의 Windows 데이터베이스 클라이언트입니다.

## 배포 파일 수정 (2026-10-21)

최초 업로드된 Windows EXE가 개발 서버(localhost)에 접속하던 빌드 오류를 수정했습니다. 프런트엔드를 내장한 EXE로 교체했으며, 개발 서버를 종료한 상태에서 실제 앱 시작·새로고침·연결 창을 검증했습니다. 기존 파일을 내려받았다면 같은 이름의 EXE를 다시 내려받아 주세요. 소스 태그와 SHA-256 체크섬도 함께 갱신했습니다.

## 탐색 메뉴 수정 (2026-10-21)

데이터베이스 메뉴가 사이드바만 접고 실행한 쿼리 화면에서 돌아오지 못하던 문제를 수정했습니다. 첫 번째 메뉴는 DB 작업 화면으로, 실행한 쿼리 메뉴는 실행 내역으로 이동하며 중복된 세션 기록 메뉴는 제거했습니다. 사이드바 접기·펴기는 상단 버튼으로 유지합니다. 화면 전환 시 작성 중인 SQL과 조회 결과를 보존합니다.

## 다운로드

- **Windows x64**: `Woojoo-0.1.0-windows-x64.exe` — 별도 설치 없이 실행합니다. Microsoft WebView2 런타임이 필요합니다.
- **소스 코드**: 이 릴리즈의 Source code (zip / tar.gz), 태그 `v0.1.0`.
- **무결성 확인**: `SHA256SUMS.txt`. 실행 파일은 코드 서명되어 있지 않습니다.

## 주요 기능

- PostgreSQL, MySQL, MariaDB, SQLite 연결과 로컬 AWS CLI 프로필·리전·RDS 선택.
- 연결 프로필, 그룹·환경, 읽기 전용 설정과 SQL 작업 공간 복원.
- SQL 파일 열기·저장, 다중 탭, 자동완성, 형식 정리, 매개변수, 스크립트 실행과 트랜잭션 제어.
- 데이터 조회·필터·정렬·편집, CSV 가져오기, CSV/JSON/SQL 내보내기와 테이블 데이터 복사.
- 스키마·테이블 상세, 테이블·컬럼 구조 변경과 실행 전 SQL 검토.
- 자동 ERD, 테이블·관계 편집, 컬럼 표시 옵션과 PNG/PDF 내보내기.
- 실행 SQL을 로컬 SQLite에 보관하는 실행 내역 페이지.
- 연결이 없을 때 user / board 테이블과 1:N 관계를 가진 로컬 SQLite 생성.
- shadcn 기반 UI, 다크·라이트 모드, 한국어·영어, Pretendard 폰트, 컨텍스트 메뉴와 앱 내 확인 대화상자.

## 참고 사항

- 연결 비밀번호는 저장하지 않습니다. SQL 파일·작업 공간·실행 내역에는 사용자가 작성한 SQL과 그 안의 값이 저장됩니다.
- ERD의 관계 편집은 다이어그램만 변경합니다. 실제 DB 제약조건 변경은 구조 관리 또는 SQL에서 수행합니다.
- AWS 조회는 연결 주소를 채우는 기능입니다. 사설망 접근, SSO 로그인과 DB 비밀번호는 사용자의 환경에서 준비해야 합니다.
- 엔진별 지원 범위, 백업 도구 의존성과 데이터 처리 제한은 README를 확인하세요.
