# Woojoo v0.1.3

작업 흐름을 "사이드바에서 찾고, 탭에서 다룬다"는 구조로 정리하고, 실수로 데이터를 잃거나 운영 DB를 바꾸는 상황을 막는 장치를 더했습니다.

## 주요 변경

### 화면 구성

- 테이블 하나는 탭 하나로 엽니다. 탭 안에서 `데이터 | 구조 | DDL | 관계`를 전환하며, 탭마다 마지막에 보던 보기를 기억합니다. 사이드바에서 처음 열면 데이터부터 보여 줍니다.
- 새 **관계** 보기는 이 테이블을 참조하는 테이블과 이 테이블이 참조하는 테이블을 외래키 컬럼과 함께 보여 줍니다. 테이블을 누르면 그 테이블의 관계로 이어서 이동합니다.
- 스키마 탭 안에서 `테이블 목록 | ERD`를 전환합니다. 이전 버전에서 열어 둔 구조·ERD 탭은 새 보기로 옮겨지고, 같은 대상의 탭이 있으면 하나로 합칩니다.
- 왼쪽 레일은 사이드바 내용(탐색기 / 쿼리 기록)만 바꾸고 열린 탭은 그대로 둡니다. 선택된 항목을 다시 누르면 사이드바가 접힙니다.
- "실행한 쿼리" 페이지와 툴바의 "SQL 기록"을 사이드바의 **쿼리 기록** 하나로 합쳤습니다. 이 연결/전체, 검색, 상태, 기간으로 거르고, 항목을 누르면 새 쿼리 탭으로 엽니다.
- 탭을 바꾸면 사이드바 트리가 해당 스키마·테이블을 펼쳐 강조합니다. 상단 경로(연결 › 스키마 › 대상)를 눌러 이동할 수 있습니다.
- 상단 오른쪽은 `● 엔진 · 호스트 · TLS` 연결 상태와 연결 추가만 남겼습니다. 언어는 설정(Ctrl+,)의 `언어 / Language`에서 바꿉니다.

### 쿼리 실행

- 쿼리 탭마다 **실행 스키마**를 고릅니다. 스키마를 생략한 SQL은 그 스키마에서 실행되며(PostgreSQL search_path, MySQL·MariaDB USE), 목록에는 사이드바 필터에 표시한 스키마만 나옵니다. 테이블 탭은 그 테이블의 스키마를 씁니다.
- 실행 중에도 SQL 편집기를 계속 쓸 수 있습니다. 실행 버튼은 경과 시간이 보이는 **중지**(Esc)로 바뀌고, 사이드바도 막히지 않습니다.
- Ctrl+Enter는 선택이 없으면 커서가 있는 문장만 실행합니다. Ctrl+Shift+Enter(스크립트), Ctrl+T/W/S, F5를 추가하고 도움말에 단축키 표를 넣었습니다.
- PostgreSQL 쿼리 제한 시간을 연결마다 설정할 수 있습니다(기본 30초, 0은 제한 없음). 시간 초과 오류에는 설정 방법을 함께 안내합니다.

### 안전 장치

- 적용하지 않은 셀 편집, 데이터 도구 변경, 커밋하지 않은 트랜잭션이 있으면 앱 창을 닫기 전에 확인합니다.
- 운영(Production) 연결은 상단에 PRODUCTION 표시가 붙고, 데이터나 구조를 바꾸는 SQL과 변경 적용 전에 대상 스키마와 함께 확인합니다.
- 결과가 500행에서 잘리면 정렬·검색·CSV 내보내기가 불러온 행만 대상이라고 알리고, 데이터 도구의 서버 정렬·필터로 안내합니다. CSV는 화면에 보이는 행을 내보냅니다.
- 트랜잭션 도중 다른 스키마의 탭에서 실행하면 먼저 확인합니다.
- 확인 창은 "버리고 닫기"처럼 실제 동작을 버튼에 적고, 파괴적인 작업은 붉게 표시합니다. 오류 알림은 닫을 때까지 남습니다.

### 그 밖의 개선

- 사이드바 테이블 목록의 불러오기·오류(다시 시도) 상태, 스키마 필터 개수 표시와 해제, 연결별 접힘 상태 저장.
- 연결 수정 화면 제목, 엔진을 바꿔도 입력한 값 유지, 오류 표시 개선. 읽기 전용 연결에서는 구조 변경 버튼을 일관되게 막습니다.
- 데이터 도구에서 삭제 예약한 행을 한 행씩 되돌릴 수 있습니다. 결과 표를 화살표·Enter·F2로 다룰 수 있습니다.
- 작은 글자를 11px 이상으로 키우고, 빠진 번역과 접근성 이름을 채웠습니다.

## 다운로드

- `Woojoo-0.1.3-windows-x64.exe`: 설치 없이 실행하는 Windows x64 앱. Microsoft WebView2 런타임이 필요합니다.
- `SHA256SUMS.txt`: 실행 파일의 SHA-256 체크섬.
- 실행 파일은 코드 서명되어 있지 않습니다. 기존 앱을 종료한 뒤 새 EXE로 실행하세요. 기존 프로필, 저장된 탭과 사용자 데이터는 유지됩니다.

## 검증

- 프런트엔드 단위 테스트 38개 통과. TypeScript/Vite 빌드 통과.
- Rust 테스트 29개 통과, 외부 DB가 필요한 4개 제외.
- UI 테스트 86개 중 84개 통과. 실패한 `structure.spec.ts`의 2개는 v0.1.2 코드에서도 같은 이유로 실패하는 기존 문제입니다.
- Windows x64 최적화 빌드 통과. 배포 EXE 실행과 창 닫기를 확인했습니다.
- 실제 PostgreSQL·MySQL 서버에서의 실행 스키마 전환과 외래키가 있는 테이블의 관계 보기는 이번 릴리스에서 실제 DB로 검증하지 않았습니다.
