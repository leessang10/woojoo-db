# Redis 작업 공간

왼쪽 앱 메뉴의 **Redis**에서 독립적으로 연결을 관리하고 키·캐시·큐를 조회합니다. 실제 연결은 Tauri 데스크톱 앱에서 사용합니다. **데모 살펴보기**는 샘플 데이터만 사용하며, 실제 연결을 하려면 **데모 종료**를 누르세요.

## 연결

연결 이름, 호스트, 포트, DB 번호와 선택적 ACL 사용자명·비밀번호를 입력하세요. 호스트는 URI가 아닌 호스트명/IP입니다. TLS를 켜면 서버 인증서와 호스트명을 검증합니다. 사용자 지정 CA와 mTLS는 지원하지 않습니다.

프로필에는 비밀번호가 포함되지 않습니다. `이 PC에 비밀번호 기억`을 선택한 경우에만 Windows 자격증명 관리자에 저장합니다. 입력한 비밀번호는 요청 전송 시 입력란에서 제거됩니다. 연결 테스트 후 필요하면 연결할 때 다시 입력하세요. 앱을 다시 켜도 자동 접속하지 않습니다.

## 키·캐시·큐

- **키:** SCAN 패턴(`user:*`)과 자료형으로 탐색합니다. 접두사 트리의 기본 구분자는 `:`이며 연결 설정에서 변경할 수 있습니다. 정확한 키 이름은 `키 직접 열기`를 사용하세요.
- **값:** String은 텍스트/JSON/Hex, Hash는 필드 표, List는 인덱스, Set은 멤버, Sorted Set은 점수, Stream은 ID와 필드로 표시합니다. 큰 값은 제한된 미리보기와 다음 항목을 사용합니다. 안전하게 표현할 수 없는 큰 JSON 정수는 원문으로 표시합니다.
- **캐시:** 패턴을 저장하고 TTL 구간을 눌러 탐색한 키를 필터링합니다. 전체 데이터의 추정 비율이 아니며 TTL은 마지막 조회 시점의 관측값입니다. hit/miss는 서버 전체 누적값입니다.
- **큐:** List/Stream 키 상세에서 `큐로 등록`을 선택하세요. List의 처리 방향은 직접 지정합니다. Stream은 그룹별 pending·소비자·idle을 조회합니다. Pending은 실패 수가 아니라 전달 후 ACK되지 않은 메시지 수입니다.
- **갱신:** 수동 새로고침이 기본입니다. 선택 항목 5초 갱신을 켜도 전체 키를 자동 재탐색하지 않으며 다른 앱으로 이동하면 갱신을 중단합니다.

## 지원 범위와 제한

Redis 6.2+ Standalone을 대상으로 구현했습니다. 확인된 Cluster는 거절하며, ACL 때문에 토폴로지를 확인할 수 없는 연결에는 범위 미확인 안내를 표시합니다. 그 경우 연결 서버의 결과를 전체 DB로 해석하지 마세요.

조회 전용입니다. 값 편집·삭제, TTL 변경, 큐 메시지 소비/ACK/재시도, BullMQ 의미 해석, Pub/Sub, Sentinel, RedisJSON과 SSH 터널은 포함하지 않습니다.

SCAN은 중복·빈 배치를 반환할 수 있으며 실행 중 변경되는 데이터의 스냅샷을 보장하지 않습니다. `더 불러오기`로 탐색을 계속하세요. 탐색 결과는 10,000키 또는 약 32MiB에서 중단하고 검색 범위를 좁히도록 안내합니다. 상세는 100항목/64KiB 미리보기, 네트워크와 IPC는 별도 상한을 적용합니다. 하나의 지나치게 큰 항목은 미리보기를 중단합니다.

프로필과 저장한 보기는 앱 데이터 영역에 저장합니다. 키 값·큐 payload·조회 결과는 자동으로 디스크에 저장하지 않습니다. 프로필 삭제는 Redis 데이터를 삭제하지 않습니다.

## 검증

프론트엔드 단위·화면 검사와 Rust의 제한된 TCP 서버 검사를 포함합니다. TCP 검사는 Redis 프로토콜·자료형·ACL·취소·크기 제한을 검증하지만 실제 Redis 서버 배포 환경의 호환성 검증을 대신하지 않습니다. 이 구현 환경에서는 Docker 엔진이 꺼져 있어 실제 Redis 서버/TLS 서버를 사용한 검증은 수행하지 못했습니다.
