# Redis App Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development or superpowers:executing-plans to implement these tasks. Preserve unrelated working changes; do not commit them.

**Goal:** Ship the approved read-only Redis workspace inside Woojoo.
**Architecture:** Independent React workspace and Rust Redis module, connected by typed IPC. Shared UI and credential primitives, no SQL model dependency.
**Tech Stack:** React/TypeScript, Tauri/Rust, bounded RESP2 transport with verified TLS if the Redis driver cannot enforce receive budgets.
**Spec:** ../specs/2026-10-25-redis-workspace-design.md

## Global Constraints
- Read-only Standalone Redis 6.2+; no queue consumption, writes, arbitrary command console, Cluster or Sentinel.
- SCAN COUNT 200; metadata batches 50; scan work <=10 iterations/1 second; index <=10,000 keys/32MiB.
- Detail 100 items; preview 64KiB; serialized IPC <=2MiB; bounded network/parser allocations.
- Connect timeout 5 seconds; query timeout 10 seconds; optional 5-second visible-only refresh.
- Original binary keys and decimal string integers; no persisted values/passwords outside credential vault.
- Existing dirty checkout retained because it contains the current shared UI required by this feature; edits remain scoped and uncommitted for review.

## Review Focus
- Empty SCAN pages/duplicates are not completion; task 2 unit tests.
- Huge single bulk values must be rejected before allocation; task 1 protocol tests.
- Late responses must not cross connections or selection; task 2 request gate tests and task 3 UI.
- Restricted ACL must degrade metadata without hiding readable values; task 1 integration tests.
- Queue observation must not alter groups/pending or lists; task 1 integration test.

## Shared IPC contract
All structs use camelCase JSON. Commands taking reads use `{request: ReadRequest}`. Others use parameters named below.

```ts
type Profile = {id:string;name:string;host:string;port:number;username:string;db:number;tls:boolean;environment:string;separator:string};
type SavedView = {id:string;profileId:string;db:number;name:string;kind:'cache'|'list'|'stream'|'favorite';pattern:string;keyBase64:string;direction:'unknown'|'left'|'right'};
type Workspace = {profiles:Profile[];views:SavedView[];credentialSupported:boolean};
type Bytes = {base64:string;text:string;utf8:boolean};
type Meta = {key:Bytes;type:string;ttlMs:string|null;length:string|null;error:string|null};
type ReadRequest = {sessionId:string;requestId:string;generation:number;keyBase64?:string;pattern?:string;typeFilter?:string;cursor?:string;offset?:string;group?:string};
type Scan = {keys:Meta[];nextCursor:string;observedAt:number;partial:boolean;dbSize:string|null};
type Value = {key:Bytes;type:string;length:string|null;ttlMs:string|null;rows:{id:string;cells:Bytes[]}[];text:Bytes|null;nextCursor:string|null;observedAt:number;truncated:boolean};
type Queue = {groups:{name:string;pending:string;consumers:string;lag:string|null}[];consumers:{name:string;pending:string;idle:string}[];pending:{id:string;consumer:string;idle:string;deliveries:string}[];errors:string[];observedAt:number};
```

Commands: `redis_workspace_load()` -> Workspace; `redis_profile_save({profile})`; `redis_profile_delete({id})`; `redis_view_save({view})`; `redis_view_delete({id})`; `redis_connect({profile,password:string|null,remember:boolean})` -> `{sessionId:string}`; `redis_test_connection({profile,password:string|null})`; `redis_disconnect({sessionId})`; `redis_forget_password({id})`; `redis_scan({request})` -> Scan; `redis_read_value({request})` -> Value; `redis_key_metadata({request})` -> Meta; `redis_queue_inspect({request})` -> Queue; `redis_server_info({request})` -> `{info:string|null;dbSize:string|null;errors:string[]}`; `redis_cancel({sessionId,requestId})`. Errors are sanitized `CODE: detail` strings. test_connection returns void.
